# Little Hacker's Quest (LHQ) - Voice Edition

48개월(만 4세) 아이를 위한 웹 기반 CLI 놀이 게임입니다. 텍스트를 아직 읽지 못해도, 한국어 TTS 안내를 들으며 알파벳을 찾아 입력할 수 있습니다.

## 실행 방법

1. `index.html`을 브라우저에서 엽니다.
2. 큰 `시작!` 버튼을 누르면 음성 안내가 시작됩니다.

## 구현된 기능

- 레벨 진입 시 상황 설명 + 철자 가이드 TTS 자동 재생
- 정답 입력 시 칭찬/상황 변화 TTS 재생
- 오답 입력 시 재도전 안내 TTS
- `키 입력 알파벳 읽기` 토글 제공
- 시작 화면에서 챕터 선택, 클리어한 챕터는 ✓ 표시 (브라우저에 저장)
- 7개 챕터 / 60개 미션

| 챕터 | 내용 | 예시 |
|---|---|---|
| CH1~3 알파벳 | A~Z 큰 글자 + 그림 단어 (A is for apple) | `a`, `b`, `c` |
| CH4 첫 명령어 | 2~3글자 명령으로 장면 바꾸기 | `on`, `hi`, `go`, `eat`, `pop` |
| CH5 영어 단어 | 세 글자 영어 단어 만들기 | `cat`, `dog`, `bus` |
| CH6 대시 하나 `-` | 한 글자 옵션 (단어의 첫 글자) | `on -r`, `go -f` |
| CH7 대시 두 개 `--` | 같은 옵션을 단어로 | `on --red`, `go --fast` |

- `-r` 과 `--red` 처럼 짧은/긴 옵션이 같은 뜻이라는 실제 CLI 규칙을 그대로 연습해요.
- 입력은 대소문자, 대시 앞뒤 띄어쓰기, iOS가 `--` 를 `—` 로 바꾸는 경우까지 너그럽게 받아줘요.

## 브라우저 참고

- Web Speech API가 지원되는 최신 Chrome/Edge에서 가장 안정적으로 동작합니다.
- 브라우저 정책 때문에 첫 음성 재생은 사용자 클릭(시작 버튼) 이후 동작하도록 구성되어 있습니다.
